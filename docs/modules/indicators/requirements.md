# indicators 模块｜需求

## 目标
- 基于分钟K与聚合K计算指标；参数可配置；结果可复现。

## 范围（已确认）
- 支持短线 + 波段使用的指标集合（初版提供常用指标，后续可扩展）

## 模块边界
- 本模块负责：指标计算与参数定义；输出与输入 Bar 对齐的序列结果。
- 本模块不负责：数据获取（data 模块）、信号决策（signals 模块）、UI 与推送。

## 指标清单（初版）
通用（短线/波段均会用到）：
- SMA/EMA（多周期）
- MACD（DIF/DEA/HIST）
- RSI
- ATR
- BOLL（上/中/下轨）
- VOL_SMA（成交量均线，用于放量倍数）

## 默认参数（初版）
短线（建议用于 5m/15m）：
- EMA：5/10/20
- MACD：12/26/9
- RSI：14
- ATR：14
- BOLL：20, 2
- VOL_SMA：20

波段（建议用于 60m/日线过滤）：
- EMA：20/60
- MACD：12/26/9
- RSI：14
- ATR：14
- BOLL：20, 2

## 输入与输出约定
- 输入：`list[Bar]`（按时间递增）
- 输出：每个指标输出与输入等长的 list；无法计算的前置位置用 `None` 占位（例如 SMA 需要足够窗口）
- 必须可复现：同一输入 bars + 同一参数 → 同一输出
- 需要可序列化：指标结果必须能被 signals/storage 模块记录（后续对接）

## 约束
- 同一输入数据 + 同一参数 → 同一输出
- 指标参数快照需可被日志/复盘模块引用（字段细则后续补充）

## 验收点（待补充）
- 对给定 bars，能计算上述指标并输出对齐序列
- 指标结果可用于 signals 模块生成原因解释（取最后一个非 None 值即可）
