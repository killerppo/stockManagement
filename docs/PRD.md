# A股自选股分钟级信号工具（本地脚本）｜需求文档 v0.3（精简版）

> 目标：先把“核心功能完整可用”做出来；不做通知推送、不做下单。

## 1. 已确认信息（范围锚点）
- 市场：A股
- 运行形态：本地脚本
- 频率：分钟级（1m 为基准；5m/15m/60m 可由 1m 聚合；当 1m 历史覆盖不足时，允许直接使用数据源提供的高周期分钟 K）
- 交易风格：短线 + 波段
- 自选规模：约 50 只股票
- 通知/推送：先不做（只在工具界面/输出中展示信号）
- 信号输出：必须给出「入场价区间 / 止损位 / 止盈位（按规则自动计算）」并可解释触发原因
- 原则：数据源优先使用免费的

- 产品级需求：`docs/PRD.md`
- 每个模块必须有两份文档：
  - 模块需求：`docs/modules/<module>/requirements.md`
  - 模块进度：`docs/modules/<module>/progress.md`

## 2. MVP 核心功能（必须有）
1) 自选股管理
- 增删改、自定义分组、备注
- 导入：支持粘贴/CSV（后续补充细节）

2) 行情与K线（分钟级刷新）
- 自选列表：显示最新价、涨跌幅、成交量/额（以数据源可得为准）、最新信号摘要
- 个股详情：K线 + 指标叠加 + 信号点标注 + 触发原因明细

3) 指标计算（参数可调）
- 面向短线/波段的常用指标（具体清单与默认参数后续补充）
- 指标必须可追溯：同一输入数据下结果可复现

4) 信号引擎（规则化、可解释）
- 输出信号类型：买入候选 / 卖出或减仓候选 / 风险或止损 / 观察
- 支持“冷却/去抖”：避免同一标的在短时间内反复触发同类信号
- 每条信号必须能展开查看：命中条件、阈值、当时指标值（用于复盘）

5) 复盘与日志
- 记录：信号触发时间、触发价、周期、参数快照（策略版本/参数）、指标快照、原因列表
- 查询/筛选：按日期、股票、信号类型（导出CSV后续补充）

## 3. 数据源要求（免费优先）
### 3.1 约束与目标
- 目标：能稳定获取 A股 1分钟K（盘中）与一定长度的历史K线（用于指标连续性）
- 现实约束：免费数据源常见不稳定/限流/接口变动，需要在设计上允许替换与降级

### 3.2 已确定原则（不绑定具体供应商）
- 优先使用免费数据源
- 需要支持“可替换”：数据获取层与指标/信号层解耦
- 必须做基础数据质量校验：时间对齐、缺口检测、字段异常（如开盘价为0）、复权标记（细则后续补充）

### 3.3 初始落地方案（可替换，后续根据稳定性调整）
- 盘中分钟级：优先接入“免费可用”的行情接口（可能来自开源聚合库/公开接口）
- 历史补全：优先使用带免费额度的数据服务（注册获取 Token 的方式亦可）

> 注：具体选择哪一个免费数据源/组合，以“能稳定拉到 1m 数据并可持续运行”为准；若免费方案无法满足稳定性，再升级到合规付费源（属于后续范围）。

## 4. 信号输出规范（必须包含入场/止损/止盈）
每条信号（Signal）统一输出字段：
- 标的、时间、周期（1m/5m/15m/60m/日线过滤标记）
- 方向：Entry / Exit / Risk / Watch
- 强度评分：0–100（用于排序）
- 入场价区间：`[entry_low, entry_high]`
- 止损位：`stop_loss`
- 止盈位：`take_profit`（支持 1–3 档：TP1/TP2/TP3）
- 原因：命中条件列表（显示“当前值 vs 阈值”）
- 风险标记：T+1限制、接近涨跌停、ST/退市风险、数据缺口等（先记录，细则后续补充）

止损/止盈的计算方式采用“规则化自动生成”（具体规则与默认参数后续补充），并随信号一起记录到日志，保证可复盘与可复现。
